# Muestras de piano

Salamander Grand Piano V3, de Alexander Holm — licencia [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
Fuente: https://archive.org/details/SalamanderGrandPianoV3 (vía [@audio-samples/piano-mp3](https://github.com/darosh/samples-piano-mp3), MIT).

Tres capas de intensidad (`p`, `mf`, `f`), una muestra cada tres semitonos de La0 a Do8, nombradas por su número MIDI.
Recortadas (3–9 s según el registro) y recodificadas a MP3 96 kb/s para que carguen rápido.
